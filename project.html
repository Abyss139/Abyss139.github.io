Dự án 1: Hệ thống quản lý bán hàng trực tuyến (E-Commerce Store)

Mô tả: Hệ thống quản lý kinh doanh thiết bị điện tử bán lẻ trực tuyến, hỗ trợ quy trình xử lý đơn đặt hàng tự động, theo dõi danh mục sản phẩm, quản lý tồn kho và thống kê giao dịch khách hàng.

Công nghệ sử dụng: Java Core, JDBC, Oracle Database, SQL Developer

Vai trò: Thiết kế cơ sở dữ liệu quan hệ, tối ưu truy vấn, xây dựng Backend logic

Thời gian thực hiện: 3 tháng

Dự án 2: RetailSmart ERP – Hệ thống Quản trị Chuỗi Bán lẻ Thực phẩm

Mô tả: Giải pháp ERP tinh gọn hỗ trợ doanh nghiệp đồng bộ hóa quy trình quản lý chuỗi cung ứng thực phẩm sạch. Hệ thống xử lý xuất nhập kho, kiểm soát hạn sử dụng sản phẩm, tính toán tự động chiết khấu thương mại và quản lý công nợ nhà cung cấp.

Công nghệ sử dụng: Java Swing, SQL Server, Stored Procedures, Triggers, iText (xuất báo cáo PDF/Excel)

Vai trò: Phân tích yêu cầu nghiệp vụ (BA), thiết kế kiến trúc CSDL, lập trình các Stored Procedure kiểm tra ràng buộc dữ liệu

Thời gian thực hiện: 4 tháng

Dự án 3: SmartBuilding – Hệ thống Quản lý Vận hành Chung cư Thông minh

Mô tả: Ứng dụng số hóa vận hành cho ban quản lý tòa nhà, bao gồm module quản lý nhân khẩu cư dân, cấp phát/hủy thẻ gửi xe tự động, tính hóa đơn dịch vụ (điện, nước, phí quản lý) theo biểu phí lũy tiến và ghi nhận phản ánh sự cố kỹ thuật.

Công nghệ sử dụng: Java (OOP, MVC Architecture), Oracle PL/SQL, REST API, Git

Vai trò: Xây dựng mô hình hướng đối tượng (OOP), chuẩn hóa dữ liệu quan hệ (3NF), viết Trigger kiểm soát trạng thái hợp đồng thuê

Thời gian thực hiện: 3.5 tháng
